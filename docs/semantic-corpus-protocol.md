# 真实来源语义固定评测集与离线对照协议

> 本文的57例及19/0/13对照表是当时冻结的v1单层门禁基线。实际评测器和生产代码均在结果中记录源码哈希；后续源码或准入策略变化后，应另存结果，不把本表自动作为新版本成绩。

该评测用于回答两个独立问题：原有有限规则会放行哪些错误；收紧为逐字观察或固定证据边界后，会损失多少本来正确且有用的解释。结果不得只报错误拦截率，也不得把全部拒收当作语义能力提升。

## 输入与标注性质

构建入口为 `tools/build-semantic-corpus.py`；默认产物保存在 `tests/fixtures/semantic-corpus/byd-2025-v1/`。测试目录沿用项目忽略规则，不执行 `git add -f`。语料是比亚迪2025年一季报、半年报、三季报、年报四个独立文档的选页，年报摘要不混入；四个报告不拼接成一个期间。

每条来源保存原PDF相对路径、文件SHA-256、物理页号、原生文字、文字SHA-256及 `[start,end)` 字符区间。字符区间的坐标系是本条保存的来源文字，不是PDF字节偏移。保存完整物理页不保证章节上下文完整；逐字正例仅评价“原文观察”，不评价表外事实或业务因果。半年报第166页的千元转述另带第63页报表单位原文。

历史错误保存原始候选或原最终finding的具体JSON指针、原文件路径及SHA-256；构建时核验原文件哈希并验证原始reason候选逐字段相同。不得将人为修正的文本称为真实模型输出。

| 类别 | 数量 | 来源和含义 | label_basis |
|---|---:|---|---|
| 完整物理页字面观察 | 15 | 选页原文原样保存；不构成全文分析 | regression_reference |
| 有原文支持的正确改写 | 13 | 包括金额、期间、确认条件和披露的变动原因；归因表述限定为公司披露 | regression_reference |
| 原文支持的不足边界 | 4 | 给定页面缺少未来补助、环比操作数、客户回款因果或持续经营判据；不声称全文不存在材料 | regression_reference |
| 历史实际错误 | 3 | 原始模型对象错写，以及历史最终结果的条件简化和全文范围外推 | regression_reference |
| 显式变换负例 | 22 | 改单位、期间、口径、主体、金额、否定、条件、因果或把横线当零 | synthetic |

所有标签均不是 `independent_gold`。正确改写由现有披露核对形成，错误变换由脚本明确构造，不能当作独立中文财报语义准确率样本。当前共57例，覆盖16个原PDF物理页（其中15页有完整字面正例，第63页仅作单位上下文）。

## 防泄漏和冻结

发行人、文档、原页及近重复披露均登记分组。当前只有一个发行人，季度和年度重复披露又存在关联，因此全部放入 `regression` 分区；不拆造train/dev/test，不宣称独立多发行人或文档heldout验证。后续独立验证必须补充新的发行人、文件以及在调参前冻结的测试标注，按发行人和近重复连通组一起分割。

`dataset.json` 保存候选、期望判定、标签理由和输入哈希；`sources.json` 保存完整来源；`manifest.json` 保存数据、来源、构建器及提取器版本。`--evaluate-only` 校验哈希、原文span及每例输入哈希后执行，不重读PDF重建样本。结果同时记录实际生产门禁源码哈希，源码变化后旧结果不可冒充新版本结果。

## 对照层和指标

两个真实对照均直接调用 `financial_semantics.semantic_issues`：

- `legacy_bounded`：不启用claim支持性策略，只执行已存在的对象类型与现金流因果有限规则。
- `conservative_claim_support_v1`：启用当前保守支持性策略，完整字面来源/固定边界可保留，未经验证自由改写隔离。
- `reject_all_control`：显式全部拒收对照，用于显示“无错误放行”本身没有充分价值。

这是**单层语义门禁**测试，未调用完整工作流、结构协议、source-unit父上下文准入、确定性财务计算或最终综合器。完整页面正例通过该层不能推导完整生产流程也会放行。后续结构化语义路径应在同一冻结集增加独立策略列，不能把不同层结果混写。

指标至少同时报告负例误放、正确正例准入、正确改写隔离及每类别分母。这里“隔离正确改写”表示覆盖损失，不表示程序断言该改写错误；不足边界通过不计为实质财务分析完成。平衡判定准确率只是本固定集上的二分类辅助量，不是企业财务分析准确率。

## 当前离线观测

| 策略 | 正例准入/32 | 错误放行/25 | 正确改写隔离/13 | 平衡判定准确率 |
|---|---:|---:|---:|---:|
| 原有限规则 | 32 | 23 | 0 | 54.0000% |
| 保守支持性准入 | 19 | 0 | 13 | 79.6875% |
| 全拒收对照 | 0 | 0 | 13 | 50.0000% |

保守策略挡住了本集所有错误，但也隔离了全部13条正确改写，包括公司明确披露的现金流变动原因。因此它是防止未验证解释流出的隔离机制，**不能据此称通用语义理解或有用财务解释已经完成**。下一阶段需要在不增加错误放行的前提下，恢复经来源、期间、单位、主体、关系、条件核验的正确解释覆盖。

## 复现

```powershell
uv run --no-sync python tools/build-semantic-corpus.py
uv run --no-sync python tools/build-semantic-corpus.py --evaluate-only
```

整个过程0次模型调用。默认每次执行对同一冻结输入运行两次，保存 `results.json` 和 `reproducibility.json`，要求两份结果SHA-256相同。这证明相同源码下的离线确定性，不证明外部模型重新生成结论一致。构建器不会下载材料；缺少本地原PDF或历史原始文件时应失败，不用合成文件静默替代。
