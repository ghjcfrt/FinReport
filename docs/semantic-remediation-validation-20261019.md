# 金融语义准入修复与实际结果核查（2026-10-19）

## 结论与适用范围

本次修复面向一类通用问题：结构合法、来源真实、金额正确，并不保证解释中的主体、对象、否定、条件、期间、口径及结论状态正确。新运行同时约束证据分析过程与最终报告；未知自由改写保留为未验证候选，不当成已支持事实，也不一概判作事实错误。

**已完成的是通用准入、追溯与恢复漏洞修复；尚未完成的是可靠放行自由金融解释的能力。** 最终 H1 受限样本保留程序算术及证据不足说明，不能把保守隔离造成的低分析覆盖称作财报分析全部完成。以下分别给出原始错误、实际输出、反例推翻的中间方案与最终限制。

本次主智能体直接读取原 PDF 页、原始模型候选、准入回执和报告正文，并用独立算式核对金额；子智能体另做反例审计与历史逐项检查。核查结论只针对本文件列出的有限样本，不是对所有未来财报承诺零语义错误，也不代表自由解释能力已经完成验收。

## 二、实现了什么，尚未实现什么

### 默认支持性准入

新证据工作流默认记录 `claim_support_v1`；完整综合报告记录 `final_claim_support_v1`。策略分开验证：

- 来源授权、哈希、期间、金额、公式和勾稽继续由程序执行。
- 仅完整已保存父来源上下文可作字面观察保留；局部原文单元仍为未验证候选。一句完整语法句可能丢掉前文假设或后文例外，因此不能仅按句号切分后认为独立受支持。
- 引文正文、解释正文、逐项理由分别验证。正确引文不能使其旁边的错误解释自动通过。
- 未证假设、证据不足前缀或安全模板不能为额外企业事实提供支持。
- `signal_found`、不适用、未发现等状态本身也是判断；不能仅凭安全正文取得这些状态。
- 最终报告的类型、标题、额外限制同样受约束，不能作为另一条自由断言通道。
- 未验证解释保留 `original_text`、来源范围、规则版本、`needs_review` 和 `quarantined` 回执；不发布为已支持结论。这里的 `needs_review` 表示尚未解决状态，并不证明解释错误。

这是保守支持性准入。正确的同义改写、合理但尚未建立规则证明的解释也可能被隔离，存在分析召回损失。不能把它宣传为通用中文蕴含模型，或宣称只要通过即证明全文语义正确。

### 评测而非自报语义正确

DSPy v2 评测覆盖主张正文、简要依据、主体与对象、否定或不确定性、条件、期间、口径、证据 span 和规则前提。旧 v1 仅按分类码、来源和数字比较的结果保留原义。

Signature 已定义这些输入输出要求，但尚未进入生产生成或优化器。严格参考匹配能发现标签中的不同改写，合法同义表达也可能被判不匹配；它不是自动证明原文蕴含主张。当前案例是合成或回归参考，不冒充独立金融测试金标准。详见 [评测 v2](semantic-evaluation-v2.md)。

### 新旧运行与复现

新策略写入 trace 和结果；历史缺少策略字段的运行按历史规则回放。旧报告能回放不等于通过新语义策略。检查点复用需要策略一致、输入一致，且输出可由保存的供应商响应重新构造。来源有变化时停止发布，不清空失效标志。

原文单元准入另冻结 `certified_source_unit_local_admission_v1`。同时提供单元 ID 和正文时，只接受与该单元逐字一致的正文，冲突会拒绝，不静默修字。最终规则不再根据标题、编号或表格终止行推定局部选段语义独立：即使问项、注释或子表形式完整，也可能受到前后假设、例外或回指限定。自动支持只允许保留完整已保存父来源上下文的引文；局部选段保留待核，不提供独立语义支持认证。旧策略缺失或不同的检查点不能直接沿用为当前策略成功，恢复时重新执行准入检查。
